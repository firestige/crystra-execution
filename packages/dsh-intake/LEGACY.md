# Historical compatibility source

This directory preserves the source corresponding to the previously published
`crystra-execution-intake-internal` compatibility line. It remains available for rollback analysis
and historical provenance during the migration window, but it is no longer part
of the active Execution release pipeline and must not be published.

Current DSH users should install `dsh-crystra` from
[`firestige/crystra-dsh`](https://github.com/firestige/crystra-dsh). Durable Delivery
data, user configuration, and previously published artifacts are intentionally
not removed by this retirement.
